# Inkling

손가락과 펜으로 그리는 그림 앱. 브라우저에서 바로 쓰거나 앱처럼 설치할 수 있어요.

- **안드로이드(크롬):** 주소를 열고 메뉴(⋮) → **앱 설치** (또는 "홈 화면에 추가" → 설치)
- **아이패드/아이폰(사파리):** 공유 버튼 → **홈 화면에 추가**

설치하면 주소창 없이 풀화면으로 열리고, 인터넷 없이도 동작해요.
그린 그림은 이 기기 안에만 자동 저장돼요 (서버로 보내지 않음).

## v1.7 에서 달라진 점

- **되돌리기 50단계** — 붓·모양처럼 그림 바닥을 건드리지 않는 작업은 복사 없이 기록하고, 오래된 기록은 조용히 PNG로 눌러 담아요.
- **채우기는 따로 일하는 일꾼(Worker)** 이 계산해서 큰 종이에서도 화면이 멈추지 않아요. 펜은 "반응 앞당기기"(설정에서 끌 수 있어요)를 지원해요.
- **레이어:** 합치는 방식(곱하기·스크린·오버레이 등), 알파 잠금, 아래 레이어에 맞추기(클리핑), 레이어 수는 종이 해상도에 따라 6~10개.
- **스포이트**(도구, `I`, 마우스는 `Alt`+클릭) · **화면 돌리기**(두 손가락 비틀기, `,` `.`) · **좌우 뒤집기**(`F`, 보기만 바뀌어요).
- **편의:** 두 손가락 톡 = 되돌리기, 세 손가락 톡 = 다시 하기. 단축키 `B E J G I M T V`, `[` `]` 굵기, `Space`+끌기 이동, `Ctrl+S` 저장, `0` 원래대로.
- **내보내기:** PNG · 투명 배경 PNG · JPG · WebP · 레이어별 PNG(ZIP) · 그리는 과정 영상(타임랩스). 종이 비율에 4:5, 9:16 추가.
- **백업:** 작품을 `.inkling` 파일(레이어 그대로)로 내보내고 불러오기, 모든 그림 한 번에 백업, 저장 공간 자동 삭제 보호 요청.
- **안정성:** 서비스워커를 실제로 등록해 오프라인에서 열려요(이전 버전은 등록 코드가 빠져 있었어요). 새 버전이 준비되면 알려 주고, 자동 저장이 계속 실패하면 경고해요.
- **보기 도움:** 참고 사진 띄우기(스포이트로 색도 집을 수 있어요), 삼등분·황금비·대각선·격자·1점 투시 가이드. 둘 다 저장되는 그림에는 들어가지 않아요.
- **접근성:** 확대 막던 설정을 풀고, 슬라이더 이름·값을 읽어 주도록 하고, 창에 이름을 붙였어요. 움직임 줄이기 설정을 따라요.

## 새 버전을 낼 때

`index.html` 의 `APP_VERSION` 과 `sw.js` 의 `VERSION` 을 같은 값으로 올려요. 서비스워커가 새로 켜지면 열려 있는 화면에 "새 버전이 준비됐어요"를 띄워요.
